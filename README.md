# CTS Mapper

Run Circle to Search or Gemini from a hardware key or gesture on Android.
Made for ColorOS (the Plus Key), but works on other phones too.

## What it does

- Gesture bar: long press the gesture bar at the bottom of the screen to run
  Circle to Search (a small invisible strip sits on top of it)
- Volume Up / Down: long press or double press
- Plus Key (or any recorded key): press or long press

You choose what each one does: Circle to Search or Gemini.

## What you need

- Shizuku installed and running
- Accessibility service turned on for this app

## How to install

1. Download CTS-Mapper.apk from the Releases page (right side of this page).
2. Install it and open the app.
3. Follow the Setup tab.
